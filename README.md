# LEAM-US  

This repository contains the model code for **LEAM-US**. We have already executed the model, and you can find details on running it, along with further instructions, in the following repository:  

🔗 [Interactive Neural Process Repository](https://github.com/Rose-STL-Lab/Interactive-Neural-Process?tab=readme-ov-file)  

## How to Use  

### Dataset Download  
Follow the **LEAM-US-specific** dataset download instructions from the linked repository above.  

### Running the Model  
Once the dataset is set up, execute the `model.ipynb` notebook to generate the model's prediction outputs.  

### Debugging & Analysis  
- Run `vis.ipynb` to visualize and debug the model execution.  
- Execute `events.ipynb` to inspect event-related debugging.  

For any questions or issues, please refer to the documentation in the linked repository.
